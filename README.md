# AlgoLabs

**AlgoLabs – Interactive Algorithm Learning Lab**

AlgoLabs is a modular Python application for learning, executing, and testing fundamental algorithms and array/list techniques through an interactive command-line interface.

## Main modules

1. Fundamental Algorithm Lab
   - GCD
   - Factorial
   - Fibonacci
   - Prime checking
   - Prime factorization
   - Number reversal
   - Decimal-to-binary conversion
   - Character-to-number conversion

2. Array & List Lab
   - Array reversal
   - Counting values
   - Maximum value
   - Duplicate removal
   - Kth smallest element
   - Array partitioning
   - Linear/binary search
   - Bubble sort

3. Quiz Lab
   - Multiple-choice algorithm questions
   - Score and accuracy calculation

## Requirements

- Python 3.9 or newer
- No external packages required

## Run

```bash
python main.py
```

## Run tests

```bash
python -m unittest discover -s tests
```
