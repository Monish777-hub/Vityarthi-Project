# Project Statement

## Project Title
AlgoLabs – Interactive Algorithm Learning Lab

## Problem Statement
Students often learn algorithms as isolated programs and may have difficulty connecting the algorithm, input, output and problem-solving process. AlgoLabs provides one interactive environment where fundamental algorithms and array/list techniques can be executed, tested and practiced.

## Objectives
- Implement fundamental algorithms in Python.
- Provide interactive input and output.
- Demonstrate algorithmic problem-solving.
- Practice arrays/lists, sets and dictionaries.
- Provide a small quiz for concept verification.
- Keep the implementation modular and testable.

## Functional Requirements
1. The system shall allow users to execute fundamental algorithms.
2. The system shall allow users to perform array/list operations.
3. The system shall provide search and sorting operations.
4. The system shall provide a quiz and calculate the score.
5. The system shall validate invalid numeric input where applicable.

## Non-Functional Requirements
1. Usability: menus and outputs should be easy to understand.
2. Maintainability: algorithms are separated into modules.
3. Reliability: invalid inputs should not crash the main menu.
4. Portability: the application should run using standard Python without external packages.
5. Testability: core functions should have automated unit tests.

## Inputs
Numbers, arrays/lists, search values, choices and quiz answers.

## Outputs
Algorithm results, transformed arrays, search/sort results and quiz score/accuracy.

## Technology
Python 3.x, JSON, unittest.

## Scope
The first version focuses on the CSE1021-level algorithms and data structures. GUI, advanced visualization and persistent user profiles are future enhancements.
